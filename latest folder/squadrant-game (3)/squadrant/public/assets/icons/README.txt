SQUADRANT — Icon Asset Folder
================================

Drop PNG replacements here. Then edit:
  src/components/GameIcon.js

Set the `png` field for any icon ID you want to replace:

  rocket:    { emoji:'🚀', png:'rocket.png',   label:'Rocket' },
  bomb:      { emoji:'💣', png:'bomb.png',     label:'Air Bomb' },
  ...

PNG files are auto-sized to match the emoji slot exactly.
Recommended sizes: 32x32, 48x48, or 64x64 with transparent background.

ICON IDs AVAILABLE:
  rocket, bomb, nuke, carrier, anchor, speedboat,
  fire, hit, miss, check, warning, skull, shield,
  robot, swords, gear, back, play, lightning, undo,
  easyDot, avgDot, hardDot, soundOn, soundOff, moon, sun
